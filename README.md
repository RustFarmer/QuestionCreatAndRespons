## Установка

### Вариант 1 — скачать готовую сборку

Скопируйте папку `client` на нужный компьютер.

> **Важно:** перед копированием папки `client` необходимо:
> - либо удалить файл `question.json` и вставить его из `admin/question.json`;
> - либо удалить его и просто запустить `client.exe`.

При первом запуске `admin.exe` автоматически проверяет наличие всех необходимых `.json`-файлов и создаёт недостающие.

### Вариант 2 — клонировать с GitHub

```bash
git clone https://github.com/RustFarmer/QuestionCreatAndRespons.git
```

Требуется установленный Git.

## Запуск

Из командной строки (cmd):

```bash
# Запуск для администратора
python admin/admin.py

# Запуск для клиента
python client/client.py

# Запуск режима ответов на все вопросы
python ResponseInAll/ResponseInAll.py
```

## Admin — панель администратора

### Настройка вопросов

При первом запуске в программе присутствует демонстрационный список вопросов. Убрать его можно двумя способами:

- удалить файл `question.json`;
- нажать на кнопку «Удалить вопрос» рядом с каждым вопросом.

### Создание вопроса

Форма создания вопроса содержит:

1. **Поле для ввода вопроса.**
2. **Поля для ввода НЕправильных ответов.** Сюда нужно вводить только неверные варианты — иначе ответы будут дублироваться.
3. **Поля для ввода правильного(-ых) ответа(-ов).** Можно задать несколько правильных ответов; пользователь сможет выбрать только один, но при подсчёте будет проверяться наличие любого из них.
4. **Кнопка «Сохранить».**
5. **Кнопка «Отмена» / «Закрыть форму».**

### Редактирование вопроса

Для редактирования нажмите на красную кнопку **«РЕДАКТИРОВАТЬ»** на карточке вопроса. Откроется окно, аналогичное форме создания.

### Поделиться вопросом

Кнопка **«Поделиться»** формирует ссылку вида:

```text
https://default/question=<вопрос>/answer=[<ответы>]/right_answer=[<правильные>]/question_id=<id>
```

Ссылкой можно поделиться с другим человеком.

### Список бланков вопросов

Доступен по кнопке **«Список бланков вопросов»** в левом верхнем углу.

- **«Удалить лист»** — удаляет бланк.
- **Зелёная кнопка выбора** — загружает бланк для администратора и клиента.

### Создание бланков вопросов

Чтобы создать бланк, необходимо добавить хотя бы один вопрос. После этого появится форма создания:

1. Введите название группы вопросов (например, «Философия»).
2. Нажмите **«Добавить лист»**.

Для редактирования бланка: загрузите его и добавьте/удалите/отредактируйте нужные вопросы.

### Проходная отсечка

Это настройка картинки, которую видит пользователь после нажатия кнопки «Ответить» на странице результата.

Форма настройки содержит:

1. **Поле ввода процентов** — от 0 до 100. При некорректном вводе (не число, больше 100, меньше 0, диапазон вида «10-100») выводится ошибка.
2. **Кнопка «Отправить на сервер»** — сохраняет фото и процент.
3. **Кнопка «Добавить форму»** — добавляет новую форму.
4. **Кнопка «Удалить форму»** — удаляет форму.
5. **Кнопка выбора файла** — открывает окно выбора фотографии.

Также есть кнопка **«Очистить все отсечки»**, которая удаляет все проценты и фотографии.

### Обновить id вопросов

Кнопка пересчитывает номера вопросов. Полезна после удаления вопроса или если при импорте номер отобразился некорректно.

### Сменить картинку

Позволяет установить одну картинку для всех процентов (если не хотите настраивать отсечки вручную).

Окно содержит:

1. **Название загруженного файла** (для удобства).
2. **Кнопку загрузки файла** (или перетаскивание).
3. **Кнопку «Использовать»** — для выбора уже загруженной ранее картинки (рядом отображается её название).

### Установить пароль для повторного прохождения теста

- **Стандартный пароль:** `TestePass`
- Для смены пароля нажмите соответствующую кнопку, введите новый пароль и сохраните.

Если пользователю нужно ввести пароль при тестировании, можно:

1. Открыть файл `...client/_internal/static/exe/getClientCookie/password.txt` — там будет пароль.
2. Либо просто удалить файл по пути `...client/_internal/NoAgain.txt` — это сбросит защиту от повторного прохождения.

## Client — прохождение теста

Скопируйте всю папку `client` на компьютер пользователя. При запуске открывается страница в браузере.

### Процесс прохождения

1. Выберите ответ на каждый вопрос (ЛКМ по варианту).
2. Нажмите красную кнопку **«Ответить»**.
3. Подтвердите действие — если не на все вопросы даны ответы, появится предупреждение.
4. После проверки отобразится страница результата с количеством правильных ответов и картинкой проходной отсечки.

## ResponseInAll — режим ответов на все вопросы

Модуль добавлен в версии 3.5. Позволяет отвечать на вопросы группы сразу, а не по одному.

### Кнопки интерфейса

1. **«Назад»** — возврат.
2. **«Проверить»** — при верном ответе вопрос окрашивается в зелёный, при неверном — в красный.
3. **«←» (предыдущий вопрос).**
4. **«→» (следующий вопрос).**
5. **«Закрыть»** — закрытие программы.

## Shope — магазин стилей

Добавлен в версии 4.1. При нажатии на кнопку открывается окно со списком доступных стилей/листов вопросов. Для работы требуется подключение к интернету.

### Карточка стиля

Каждая карточка содержит:

- название листа;
- тему (light/dark);
- имя пользователя, создавшего лист;
- две кнопки:
  1. **Скачать** — загружает стиль, после чего он становится доступным для выбора.
  2. **Просмотр** — открывает предпросмотр (слева — пример стиля, справа — лист с вопросами).

## Структура проекта

```text
QuestionCreatAndRespons/
├── admin/                  # панель администратора
│   └── question.json       # база вопросов
├── client/                 # клиент для прохождения теста
│   └── _internal/

│       └── NoAgain.txt

```

## Решение проблем

| Проблема | Решение |
|---|---|
| При первом запуске в списке есть демо-вопросы | Удалить файл `question.json` или нажать «Удалить вопрос» |
| Клиент не видит вопросы | Удалить `client/question.json` и скопировать из `admin/question.json`, либо запустить `client.exe` без этого файла |
| Не работает повторное прохождение | Удалить `client/_internal/NoAgain.txt` |
| Забыт пароль для повторного прохождения | Открыть `client/_internal/static/exe/getClientCookie/password.txt` или удалить `NoAgain.txt` |
| Некорректные номера вопросов | Нажать «Обновить id вопросов» |
