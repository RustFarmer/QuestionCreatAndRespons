## Терминология

- **Администратор** — человек, который создаёт вопросы.
- **Клиент** — человек, который проходит тест.

Использовать программу очень легко.

Для возврата на главную страницу, помимо кнопок «Назад», можно нажимать на названия страниц.

## Быстрый старт

Перед тем как скопировать папку `client`, необходимо:

- либо удалить файл `question.json` и вставить его из `admin/question.json`;
- либо удалить `question.json` и запустить просто `client.exe`.

При запуске `admin.exe` сначала проверяется наличие всех нужных файлов формата `.json`. Если их не хватает — программа создаст их.

## Admin

### Список вопросов

При первом запуске в программе будет примерный список вопросов.  
Его можно убрать:

- удалив файл `question.json`;
- либо нажав на кнопку удаления вопроса.


1. Список вопросов.
2. Кнопка для создания вопросов.


---

### Создание вопроса

После нажатия на кнопку **«Создать вопрос»** откроется форма для создания вопроса.


1. Поля для ввода вопроса.
2. Поля для ввода **неправильных** ответов.
3. Поля для ввода **правильного/правильных** ответов.
4. Кнопка, чтобы сохранить вопрос.
5. Закрыть форму создания вопроса.

Разберём каждый пункт подробнее.

**Первый пункт:** поле для ввода вопроса.

**Второй пункт:** поля для ввода неправильных ответов.  
Если в него ввести правильный ответ, то ответы будут дублироваться, потому что ответы на вопрос у пользователя берутся из полей «Ответы» и «Правильные ответы». Поэтому в это поле надо вводить только **неправильные** ответы.

**Третий пункт:** для ввода правильных ответов. Предусмотрено, если необходимо сделать несколько правильных ответов. Но пользователь сможет выбрать только один ответ, при этом при подсчёте правильных ответов будет проверяться наличие одного из них.

**Четвёртый и пятый пункт:** «Сохранить» и «Выйти из создания вопроса».

### Поделиться


Данная кнопка служит для того, чтобы делиться вопросом с другим человеком.

Пример использования:

`https://default/question=ыва/answer=['ыва']/right_answer=['ыва']/question_id=0`

### Редактирование вопроса


После нажатия на неё открывается окно редактирования.


Пользоваться им так же, как и при создании вопроса.

---

### Список бланков вопросов

Данная кнопка находится в левом верхнем углу.


После нажатия открывается окно.


1. Кнопка удалить.
2. Выбрать лист.

Разберём, что делает каждая кнопка:

- **Кнопка 1** — удаляет лист.
- **Кнопка 2** — загружает лист администратору и клиенту.

---

### Создание бланков вопросов

Чтобы создать бланк вопросов, необходимо добавить хотя бы один вопрос. Тогда появится кнопка создания бланка.


Необходимо ввести название и нажать на кнопку **«Добавить лист»**.

Если вам необходимо отредактировать какой-нибудь лист, его можно загрузить и как добавить, так и удалить, и редактировать вопросы.

---

### Проходная отсечка

Проходная отсечка — это настройка картинки, которую видит пользователь после нажатия кнопки **«Ответить»**.


После нажатия на неё появляется форма.


1. Поле ввода количества процентов.
2. Кнопка «Отправить на сервер».
3. / 4. Добавить / удалить форму.
5. Выбрать файл.

Разберём каждую из них:

1. В данное поле надо вводить проценты от 0 до 100. При вводе не числа, либо больше 100, либо меньше 0 — выведет ошибку и не сохранит. При вводе числа не надо вводить диапазоны, например `10-100` или `24-56`. Программа выведет ошибку, потому что она всегда берёт ваше число и считает его до 100 либо до большего числа, которое вы вводили.
2. **«Отправить на сервер»** — эта кнопка фактически сохраняет ваше фото и процент.
3. / 4. Они добавляют и удаляют форму.
5. При нажатии откроется окно, в нём надо выбрать фотографию.

Также там есть кнопка **«Очистить все отсечки»**.


Она удаляет все проценты и фотографии.

---

### Обновить id вопросов


Данная кнопка обновляет номера вопросов.  
Её можно использовать когда угодно, но она может пригодиться, когда удалили вопрос либо при загрузке вопросов возникли ошибки и его номер неправильно импортировался.

---

### Сменить картинку


Если вы не хотите проставлять проценты, то можете просто сменить картинку для всех процентов при помощи данной кнопки.

Окно при нажатии на данную кнопку:


1. Название вашего файла при загрузке.
2. Кнопка для загрузки файла.
3. Кнопка для использования уже загруженных файлов.

Разберём все кнопки:

1. После загрузки вашего файла там будет отображаться его название для удобства.
2. Кнопка для загрузки файла, либо можно перетащить файл в неё.
3. Кнопка, с помощью которой можно использовать уже загруженную картинку, а рядом с ней — её название.

## Client

Для пользователя необходимо скопировать всю папку `client`.

При открытии открывается страница браузера.

1. Карточка вопроса.
2. Ответить на вопрос/вопросы.

Для того чтобы ответить на вопрос, необходимо ЛКМ нажать на ответ.  
После ответов на все вопросы необходимо нажать на красную кнопку **«Ответить»**.

После этого нужно подтвердить свои ответы.


После проверки вам объявят количество правильных ответов.


1. Количество правильных ответов.
