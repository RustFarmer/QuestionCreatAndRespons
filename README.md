Руководство по пользованию
Перед тем как скопировать папку client необходимо: либо удалить файл question.json и вставить его из admin/question.json, либо удалить его и запустить просто client.exe.
При запуске admin.exe с начала проверяются наличие всех нужных файлов формата .json и если их не будет хватать то он и создаст
Терминология данного руководства:
	Администратор – человек который создает вопросы.
	Клиент – человек который проходит тест.
Использовать программу очень легко.
Для того что бы вернуться на главную страничку помина кнопок назад предусмотрено нажатия на названия страниц(пример 1).
 
Пример 1.
 

Admin
1)Перед тем как дать ее пользователям надо настроить вопросы:
Настройка вопросов 
Рисунок 1   - Список вопросов.
 1) Список вопросов 2) Кнопка для создания вопросов
При первом запуске в программе будут  примерочный список вопросов(1). Их можно убрать либо удалив файл question.json либо нажать на кнопку(Рисунок 2)(Указанно стрелочкой).
 
Рисунок 2 – Указатель на кнопку удалить вопрос.
Создание вопроса:
После нажатия на кнопку «создать вопрос» откроется форма для создана вопроса(Рисунок 3)
 
Рисунок 3 – Форма создания вопроса.
1.Поля для ввод вопроса;2.Поля для ввода НЕ правильных ответов; 3. Поля для Ввода правильного/ных ответа/ов; 4. Кнопка что бы сохранить вопрос; 5. Закрыть форму создания вопроса.
Разберем каждый пункт подробнее.
Первый пункт: Поле для ввода вопроса.
Второй пункт: Поля для ввода Не правильных ответов. Если в него ввести правильный ответ то ответы будут дублироваться потому что ответы на вопрос у пользователя берется из полей «ответы» и «правильные ответы». Поэтому в это поле надо вводить только НЕ правильные ответы.
Третье пункт: Для ввода правильных ответов предусмотрено, если необходимо сделать несколько правильных ответов. Но пользователь сможет выбрать только один ответ, но при подсчете правильных ответов будет проверяться наличие одного из них. 
Четвертый и пятый пункт: Сохранить | Выйти из создания вопроса.
 Поделиться
 
Рисунок 4 – Кнопка поделиться
Данная кнопка служит для того что бы делиться данным вопросом с другим человеком (пример использования https://default/question=ыва/answer=['ыва']/right_answer=['ыва']/question_id=0).

Создание бланков вопросов
Что бы их создать необходимо добавить ≤ 1 вопрос. Тогда появиться кнопка(Рисунок 9).
 
Рисунок 9 – Создания бланка вопросов.
Необходимо вести название и нажать на кнопку добавить. Если вам необходимо отредактировать какой-нибудь лист то его можно загрузить и как добавить так и удалить и редактировать вопросы.
Проходная отсечка
Проходная отсечка это настройка картинки который видит пользователь после нажатия кнопки «Ответить»(Рисунок 10).
 
Рисунок 10 – Проходная отсечка.
После нажатия на нее у вас появляется форма (Рисунок 11).
 
Рисунок 11 – Форма проходной отсечки.
1. Поле ввода количества процентов;2. Кнопка отправить на сервер;3/4 добавить\удалить форму; 5 Выбрать файл
Давайте разберем каждую из них:
	1.В данное поле надо вводить проценты от 0 до 100, при вводе либо не число,  либо больше 100, либо меньше 0 то выведет ошибку и не сохранит. При вводе числа не надо вводить так ( 10-100 либо 24-56) программа выведет ошибку потому что он всегда берет ваше число и считает его до 100 либо до большего числа которое вы водили.
	2. Отправить на сервер эта кнопка фактически сохраняет ваше фото и процент.
3/4. Они добавляют и удаляют форму.
5. При нажатия отроется окно в нем надо выбрать фотографию

Так же там есть кнопка «Очистить все отсечки» (Рисунок 12). 

 
Рисунок 12 – Очистить все отсечки
Она удаляет все проценты и фотографии.
Обновить id вопросов
Рисунок 13.
 
Рисунок 13 – Обновить id вопросов.
Данная кнопка обновляет номера вопросов. Ее можно использовать когда угодно, но она может пригодиться, когда удалили вопрос либо при загрузки вопросов возникли ошибки и его номер не правильно импортировался.
Сменить картинку
Рисунок 14.
 
Рисунок 14 – Сменить картинку.
Если вы не хотите проставлять проценты то можете просто ее сменить для всех процентов при помощи данной кнопки. Окно при нажатия на данную кнопку (Рисунок 15).
 
Рисунок 15 – Окно сменить картинку.
1. Название вашего файла при загрузки; 2. Кнопка для загрузки файла; 3. Кнопка для использования уже загруженных файлов.
Давай разберем все кнопки:
	1. После загрузки вашего файла там будет отображать его названия для удобства.
2. Кнопка для загрузки файла либо можно его перетащить в нее.
3. Кнопка с помощью, которой можно использовать уже загруженную картинку, а рядом с ней ее название.
